# Security Policy

## Supported versions

This project is actively maintained in its current main branch.

## Reporting a vulnerability

Please report security issues privately by opening a GitHub security advisory or contacting the maintainer directly through the repository owner.

Do not disclose vulnerabilities publicly until a fix has been prepared and released.

## Best practices

- keep dependencies up to date
- avoid committing secrets, tokens, or private model credentials
- store Hugging Face credentials in a local environment file or secure secret store
- review any model or dataset additions before pushing to a public repository
